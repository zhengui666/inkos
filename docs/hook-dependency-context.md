# Story hooks and dependent context

Keep hooks, established facts, character knowledge, summaries and dependencies in the Work's professional domain data. Durable content preparation reads the current domain and relevant previous content; review may return newly established story state for the same saved version.

A hook's prerequisite is not automatically resolved when its dependent hook advances. Preserve chronology, who knows a fact, source evidence, unresolved promises and downstream consequences. Planning intentions are not new established facts; an author plan change does not rewrite previously saved prose.

Use `work_update` / `inkos work update --changes` to adjust relevant domain data and `materials_query` for source evidence. Do not create a second story executor, transcript recovery chain or authoritative Markdown projection store. Imported legacy hook structures remain readable domain data.

For branching content, preserve explicit variable conditions/effects and validate reachable routes with the professional StoryGraph parser. A common merge node must not unconditionally announce mutually exclusive facts.
